# Hyl1a-web — Frutiger Version

A web project built around the Frutiger Aero aesthetic.

## What is it?

This version of Hyl1a-web focuses on a colorful, nostalgic and early-2000s-inspired interface.

It mixes custom visuals, sounds, videos and UI elements to create a full Frutiger Aero-style experience.
